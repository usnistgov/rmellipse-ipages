Installation¶

This guide provides instructions for installing Rocky Mountain Ellipse.

Dependencies¶

sudo apt install libhdf5-dev gnome-keyring

uv Installation¶

uv add git+https://github.com/usnistgov/rmellipse --branch stable

Pip Installation¶

pip install git+https://github.com/usnistgov/rmellipse@stable
