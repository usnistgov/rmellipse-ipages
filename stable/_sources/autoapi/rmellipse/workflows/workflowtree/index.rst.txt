   Execute a set of concurrent jobs in wft.

   :param jobs: List of jobs to execute concurrently.
   :type jobs: list[job]
   :param group_name: Name of group, used for printing.
   :type group_name: str
   :param max_threads: Max number of threads (i.e. subprocesses) that

   :type max_threads: int

   :raises TypeError: If non-jobs are passed.
