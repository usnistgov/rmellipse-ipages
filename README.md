rmellipse-ipages
================


This repository hosts the build files for the static webpage documentation
built by [GitHub Docs](https://github.com/usnistgov/rmellipse). Please refer to
that repository for more information.

### Note
Currently, the sphinx-multiversion package uses the same python environment for every
documentation build, which I think will cause compatability issues with documentation that needs
to execute and test code. I think I can fix that by pulling a branch
